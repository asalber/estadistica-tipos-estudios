# Tipos de Estudios Estadísticos
Tipos de estudios estadísticos más habituales y su diseño, análisis e implementación con R, en formato de libro [Quarto](https://quarto.org).

## Contenidos
Un capítulo por cada tipo de estudio estadístico: estudios descriptivos, transversales, de cohortes, de casos y controles, ecológicos, experimentales, cuasiexperimentales, y encuestas.

## Compilar el libro
```
quarto render
```

El libro compilado en HTML se genera en la carpeta `docs`, lista para publicarse con GitHub Pages.
